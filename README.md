# Poupe

PWA mobile-first para acompanhamento de metas financeiras por meio de desafios de depósitos.

## Executar

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```

Os dados inseridos são persistidos no armazenamento local do dispositivo. O perfil permite exportar e importar um backup completo em JSON.
